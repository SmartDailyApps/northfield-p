# Self-hosted runtime assets

These files are vendored for the static site runtime and are not loaded from a CDN:

- AOS `2.3.4` — `/assets/js/aos.js` and `/assets/css/aos.css`
- Ionicons `7.1.0` — `/assets/js/ionicons/`
- Formspree Ajax `1.1.5` — `/assets/js/formspree-ajax-1.1.5.js`

The package licenses are kept beside the vendored assets. Update the version and
license together if a future maintenance pass replaces one of these packages.
